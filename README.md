# Znavvy — Live Showroom & Multi-Marketplace Price Comparator

Znavvy adalah platform komparasi harga real-time bebas zonk yang menyajikan perbandingan harga produk resmi lintas marketplace terpercaya di Indonesia (Shopee, Tokopedia, Blibli, Lazada).

- **Website Resmi:** [https://znavvy.github.io/](https://znavvy.github.io/)
- **Fitur Utama:**
  - Real-time marketplace showdown dengan verifikasi seller tier (Official Store, Shopee Mall, LazMall, Star+).
  - Filter interaktif varian & warna (AI-filtered).
  - Visual 60 FPS motion & carousel slide preview.
  - Dual-Theme System (Default Light Mode & Night Mode) dengan standar aksesibilitas kontras tinggi.
